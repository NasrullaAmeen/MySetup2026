# Contributing

This is a private, personal notes repo (see [LICENSE](LICENSE)) — it isn't
open for outside contributions.

## Conventions for future edits

- Keep each doc scoped to its topic: [HARDWARE.md](HARDWARE.md),
  [NETWORKING.md](NETWORKING.md), [ProxDev.md](ProxDev.md),
  [ProxLab.md](ProxLab.md).
- Update cross-references (the "Other docs" / "See also" links) when adding
  or renaming a doc.
- Note the date at the top of a doc when making a significant change to it.
- Log notable changes in [CHANGELOG.md](CHANGELOG.md).
- Double-check no real credentials (Wi-Fi passwords, keys, tokens) get
  committed — use placeholders like `psk="..."` as the existing docs do.
